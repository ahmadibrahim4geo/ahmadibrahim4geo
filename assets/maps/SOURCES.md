# Map assets

- `land-110m.geojson`: Natural Earth 1:110m land, obtained from [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson). Natural Earth data is [public domain](https://www.naturalearthdata.com/about/terms-of-use/).
- `globe.svg`: derived fallback using the same land geometry with a D3 orthographic projection centred on the Egypt/Saudi Arabia region.
- Globe points indicate regional context only; they are not survey coordinates, client project sites, live GPS positions or measurements.
- D3 7.9.0 is stored locally in `../vendor/d3.v7.min.js`. Its ISC license is preserved in `../vendor/D3-LICENSE.txt`.

The world globe is a cartographic illustration for the portfolio. It does not show a live project dataset.
