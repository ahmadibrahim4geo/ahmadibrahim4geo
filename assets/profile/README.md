# GitHub profile introduction

The English and Arabic README files use responsive profile cards and linked SVG action buttons. The cards summarize the existing CV: GIS and stormwater networks, hydrological drafting, InfraWizard, 5+ years of experience, six geographic atlases, projects in Egypt and Saudi Arabia, and GOPP Expert Assistant registration.

`header-source.html` is the editable layout. Open it with `?lang=en` or `?lang=ar` and capture `.header` at 1200 × 490 and 720 × 560 CSS pixels, with device scale factor 2, to regenerate the desktop and mobile PNGs. The portrait comes from `../ahmad-ibrahim.png`; its contents have not been retouched.

The Email, LinkedIn and GitHub buttons embed the existing vector marks from `../brands/gmail.svg`, `../brands/linkedin.svg` and `../brands/github.svg`. Their upstream sources and licenses remain recorded in `../brands/manifest.json` and `../brands/licenses/`. Portfolio, document and language symbols are original interface icons, not product logos. All buttons have text labels and accessible names in the README.

The remaining sections use native GitHub headings, tables, explicit navigation anchors and labeled action buttons. Project descriptions, repository targets and development status come from the existing bilingual project catalog. Project marks are reused from `../project-logos/`, with provenance in `../project-logos/SOURCES.json`; projects without verified logos remain text-only. `project-portfolio.png` places the existing white signature on a dark tile for visibility in both GitHub themes.

`software-badges-source.html` contains the 17 CV software labels and references their existing original marks in `../brands/`. Capture each `.badge` at device scale factor 2 to regenerate `tool-*.png`, and capture `#portfolio-mark` for the signature tile. These are presentation thumbnails, not replacements for the original logo files. InfraWizard uses its CADValley vendor mark and StormCAD uses its Bentley vendor mark, as in the portfolio source records. Working software and AI-assisted development technologies stay in separate sections.

The contact section has desktop and mobile SVG banners plus Email, LinkedIn, GitHub and Website actions. The email address is also available as selectable text. Website maintenance and asset-source links remain accessible in a collapsed documentation section.
