# GitHub profile introduction

The English and Arabic README files use responsive profile cards and linked SVG action buttons. The cards summarize the existing CV: GIS and stormwater networks, hydrological drafting, InfraWizard, 5+ years of experience, six geographic atlases, projects in Egypt and Saudi Arabia, and GOPP Expert Assistant registration.

`header-source.html` is the editable layout. Open it with `?lang=en` or `?lang=ar` and capture `.header` at 1200 × 490 and 720 × 560 CSS pixels, with device scale factor 2, to regenerate the desktop and mobile PNGs. The portrait comes from `../ahmad-ibrahim.png`; its contents have not been retouched.

The Email, LinkedIn and GitHub buttons embed the existing vector marks from `../brands/gmail.svg`, `../brands/linkedin.svg` and `../brands/github.svg`. Their upstream sources and licenses remain recorded in `../brands/manifest.json` and `../brands/licenses/`. Portfolio, document and language symbols are original interface icons, not product logos. All buttons have text labels and accessible names in the README.
